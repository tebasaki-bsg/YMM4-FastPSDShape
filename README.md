# 高速PSD図形（YMM4FastPsdShape）

製作者：Tebasaki
配布場所：https://github.com/tebasaki-bsg/YMM4-FastPSDShape/releases
作品ID（ニコニコの親作品登録）：sm47054167

## 概要

ゆっくりMovieMaker4（YMM4）の図形の種類に「高速PSD」を追加する図形プラグインです。
PSD ファイルを図形アイテムとして置き、アイテムごとにレイヤーの表示（差分）を切り替えられます。300MB を超える大きな PSD や、数千レイヤーの PSD でも軽く動くように作っています。

| 機能 | 内容 |
|---|---|
| 高速な読み込みと表示 | 開くときはレイヤーの情報だけを読み、表示するレイヤーだけを展開します。合成結果は1枚の画像にまとめ、同じ PSD・同じ表示のアイテムどうしで共有します |
| レイヤーの切り替え | レイヤー欄のチェックで表示を切り替えます。中クリックで、そのパーツだけを表示できます。サムネイルにカーソルを合わせると、右隣に拡大して表示します |
| プリセット | 今の表示に名前を付けて保存し、一覧から選べます（同じ PSD を使う図形アイテムで共通）。★でお気に入りにすると、一覧の上に並びます |
| 高速PSD立ち絵から取り込み | 高速PSD立ち絵プラグインのプリセットを取り込めます（立ち絵側のファイルは変更しません） |
| 名前のルール | 「*」（同じフォルダで1つだけ表示）、「!」（常に表示）、「:flip」（反転したときだけ使う。PSDTool と同じ）のルールに対応しています。アイテムごとにオン・オフできます |
| 反転 | なし・左右・上下・上下左右から選べます。「:flip」ルールがオンなら、反転用のパーツに入れ替えます |
| ドラッグ＆ドロップ | PSD をタイムラインにドラッグ＆ドロップすると、「高速PSD」の図形アイテムとして置きます |
| 外部での編集の反映 | PSD を外部で上書きすると、表示中のアイテムにもすぐ反映します |

## インストール方法

1. [Releases](https://github.com/tebasaki-bsg/YMM4-FastPSDShape/releases) から `YMM4FastPsdShape.ymme` をダウンロードする。
2. YMM4 を終了してから、`YMM4FastPsdShape.ymme` をダブルクリックし、表示される画面に従ってインストールする。

## 使用方法

1. YMM4 を起動し、図形アイテムを追加する（PSD をタイムラインにドラッグ＆ドロップしても置けます）。
2. 図形アイテムの「図形の種類」で「高速PSD」を選び、「PSDファイル」で PSD を指定する。
3. 「レイヤー」欄で表示するパーツを選ぶ。
   - チェックで表示を切り替えます。このアイテムで変えたパーツは太字になります。
   - パーツを中クリック（ホイールを押す）すると、そのパーツだけを表示し、同じフォルダのほかのパーツ（フォルダも）をオフにします。
   - 「リセット」で、このアイテムで変えた内容を取り消し、PSD の状態に戻します。
4. よく使う表示は、プリセットとして保存する。
   - 「保存」で今の表示をプリセットにし、一覧から選ぶとアイテムにコピーされます（その後も自由に変えられます）。
   - 「立ち絵から取り込み」で、高速PSD立ち絵のプリセットをコピーできます。
   - 一覧を開いて名前の左の★をクリックすると、お気に入りとして一覧の上に並びます。

### 図形アイテムの設定

| 設定 | 初期値 | 内容 |
|---|---|---|
| PSDファイル | なし | 表示する PSD（.psd のみ） |
| 反転 | なし | なし・左右・上下・上下左右。YMM4 本体の「左右反転」とは別のもので、一緒に使うと元の向きに戻ります |
| 「*」ルール | オン | 同じフォルダで名前が「*」で始まる要素は、1つだけ表示します |
| 「!」ルール | オン | 名前が「!」で始まる要素は、常に表示します（反転用の要素は除く） |
| 「:flip」ルール | オン | 名前の末尾が「:flipx」（左右）「:flipy」（上下）「:flipxy」（上下左右）の要素を、反転したときだけ使う反転用として扱います |
| フォルダのクリッピング | オフ | オフ：Photoshop 準拠（フォルダ自体のクリッピングを無視）、オン：CLIP STUDIO PAINT 準拠 |
| レイヤー | - | プリセットとレイヤーの一覧 |

### プラグインの設定

YMM4 の「設定」→「図形」→「高速PSD」で変えられます。

| 設定 | 初期値 | 内容 |
|---|---|---|
| PSD をドラッグ＆ドロップしたら高速PSDの図形アイテムとして置く | オン | オフにすると、YMM4 の標準どおり画像アイテムとして置かれます |
| 合成結果を1枚の画像にまとめる | オン | 表示を切り替えたときに1回だけレイヤーを重ね、その画像を使い回します。オフにすると毎フレーム GPU で重ねます（速さの比較用） |
| サムネイルキャッシュの保存場所 | 空欄（既定の場所） | レイヤー一覧のサムネイルを保存する場所です。キャッシュの削除もここで行えます |
| 詳細ログを出力する | オフ | 不具合の調査用です |

### ドラッグ＆ドロップについて

- 置く位置は YMM4 の標準のドロップと同じです（再生位置に、画面に見えている一番上のレイヤーから空きを探して置きます）。長さや位置などは「図形アイテムの既定値」に従います。
- 複数の PSD をドロップしたときの並べ方は、YMM4 の「複数アイテムの配置方向」の設定に従います。「元に戻す」（Ctrl+Z）1回で、ドロップした PSD のアイテムをまとめて取り消せます。
- PSD 以外のファイルを一緒にドロップしたときは、PSD 以外はいつもどおり置かれます。

## アンインストール方法

1. YMM4 を起動して `ヘルプ(H)` > `その他` > `プラグインフォルダを開く` をクリックする。
2. YMM4 を終了する。
3. `YMM4FastPsdShape` という名前のフォルダを削除する。
4. 必要に応じて、`%LOCALAPPDATA%\YMM4FastPsdShape\`（サムネイルのキャッシュとログ）と、PSD の横の `<PSD名>-ymmfastpsdshape.json`（プリセット）を削除する。

## 注意点

OS：Windows 10 / 11（64bit）
ゆっくりMovieMaker4：v4.56.1.0（Lite）・v4.57.0.1（Lite）
にて動作確認をしています。

### 本プラグインが作るファイル

- PSD と同じフォルダの `<PSD名>-ymmfastpsdshape.json`：プリセットを保存します。PSD を移動するときは、このファイルも一緒に移動してください。
- `%LOCALAPPDATA%\YMM4FastPsdShape\Cache\`：レイヤー一覧のサムネイル（削除しても自動で作り直されます）。
- `%LOCALAPPDATA%\YMM4FastPsdShape\Logs\`：ログ（エラーと、「詳細ログを出力する」をオンにしたときの詳細）。

PSD ファイルと、高速PSD立ち絵の `<PSD名>-ymmfastpsd.json` は読み込むだけで、変更しません。

### 制限事項

- .psb（ラージドキュメント形式）には対応していません。
- 調整レイヤー、塗りつぶしレイヤー、レイヤー効果（境界線・影など）は表示されません。
- ブレンド条件、ノックアウトには対応していません（合成の機能は PSDToolKit と同等です。これらは PSDToolKit でも表示されません）。
- AviUtl 向けの出力（exo）には対応していません。
- PSD と PSD 以外のファイルを一緒にドロップしたときは、PSD のアイテムを先に置き、残りを YMM4 に渡します（ドロップしたファイルの順番どおりにはなりません。「元に戻す」も PSD の分と残りの分で別になります）。

未対応の機能を含む PSD では、レイヤー欄の下に注意が表示されます。

## 開発者向け

### フォルダ構成

```
src/FastPsd.Core/        YMM4に依存しない部分（PSD読み込み・表示状態の計算・合成手順・プリセットのファイル）
src/YMM4FastPsdShape/    プラグイン本体（FastPsd.Core のソースも取り込んで1つのDLLにする）
tests/                   テスト（FastPsd.Core.Tests）とテスト用PSDの作成スクリプト
dist/README.txt          配布物に入れる利用者向けの説明
tools/pack.ps1           配布用の .ymme を作るスクリプト（Windows。artifacts/ に出力）
```

PSD の読み込みと合成は、同じ作者の高速PSD立ち絵プラグイン（YMM4FastPsd）の仕組みを元にしています。

### ビルド方法

1. `Directory.Build.props.sample` を `Directory.Build.props` という名前でコピーし、`YMM4DirPath` を YMM4 のフォルダに書き換えます（末尾の `\` を忘れずに）。
2. `src/YMM4FastPsdShape` で `dotnet build -c Release` を実行します。
3. `bin/Release/net10.0-windows/YMM4FastPsdShape.dll` ができます。

画面は XAML ファイルを使わずコードで作っており、WPF の DLL は YMM4 のフォルダから直接参照しています。そのため Windows 以外（Linux など）でも配布用の DLL を作れます（必要なのは .NET 10 SDK だけです）。

### テスト

```
cd tests/FastPsd.Core.Tests
dotnet run -c Release -- ../fixtures/rules.psd [合成テスト用PSDのフォルダ] [速度確認用PSD]
```

`rules.psd` と同じフォルダに `flip.psd`・`mask.psd` があれば、「:flip」ルールとフォルダのマスクも確かめます。どれも `tests/fixtures` の Python スクリプトで作り直せます（`make_rules_psd.py`・`make_flip_psd.py` は psd-tools が必要、`make_mask_psd.py` は追加のパッケージ不要）。

### 配布用ファイルの作り方

Windows の PowerShell で、リポジトリのルートから次を実行すると `artifacts\YMM4FastPsdShape.ymme` ができます。

```
powershell -ExecutionPolicy Bypass -File tools\pack.ps1
```
